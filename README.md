# Python Basic Programs

A beginner-friendly collection of 10 simple Python programs for practice.

## Programs included

1. `01_hello_world.py` — Display Hello, World!
2. `02_name_age.py` — Display a name and age
3. `03_add_two_numbers.py` — Add two numbers
4. `04_swap_numbers.py` — Swap two numbers
5. `05_even_odd.py` — Check whether a number is even or odd
6. `06_largest_number.py` — Find the larger of two numbers
7. `07_positive_negative.py` — Check whether a number is positive, negative, or zero
8. `08_for_loop.py` — Print numbers using a for loop
9. `09_multiplication_table.py` — Print a multiplication table
10. `10_sum_first_10.py` — Find the sum of the first 10 natural numbers

## How to run

1. Install Python 3 from [python.org](https://www.python.org/) if it is not installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run any program, for example:

```bash
python 01_hello_world.py
```

On some systems, use `python3` instead of `python`.

These examples use only basic Python syntax and require no extra packages.
