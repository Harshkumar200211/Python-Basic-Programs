# Project: Menu-Driven Calculator

## What this project does

A console calculator that repeats until the user chooses Exit.

## Python concepts used

input(), print(), functions, float conversion, if-elif-else, while loop and arithmetic operators.

## How it works, step by step

1. Display a menu of operations.
2. Read two values using a helper that rejects non-numeric input.
3. Run the selected arithmetic operation.
4. Prevent division by zero.
5. Repeat until Exit is selected.

## File used

- `main.py — menu, input validation and calculation flow.`

## How to run

1. Install Python 3.
2. Open this project folder in a terminal.
3. Run:

```bash
python main.py
```

On some systems, use `python3 main.py`.

## Learning note

This project runs in the terminal only. It has no graphical or web frontend.

Try changing the inputs, tracing the variables and adding one small feature after the first successful run.
