# Project: Student Marks and Grade Calculator

## What this project does

Accept one student's marks in three subjects and produce a total, percentage, result and grade.

## Python concepts used

Variables, lists, for loop, input validation, sum(), all(), zip() and conditions.

## How it works, step by step

1. Collect the student name.
2. Read marks for three subjects, accepting only values from 0 to 100.
3. Calculate total and average percentage.
4. Pass the student only when every subject has at least 33 marks and the average is at least 40%.
5. Assign a grade using the example percentage bands.

## File used

- `main.py — mark entry, calculations and result report.`

## How to run

1. Install Python 3.
2. Open this project folder in a terminal.
3. Run:

```bash
python main.py
```

On some systems, use `python3 main.py`.

## Learning note

The grade thresholds are for practice. Replace them with your university's official grading rules when required. Console only; no frontend.

Try changing the inputs, tracing the variables and adding one small feature after the first successful run.
