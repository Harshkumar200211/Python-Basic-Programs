# Project: Contact Book

## What this project does

Save contact names, phone numbers and optional email addresses with add/update, view, search and delete options.

## Python concepts used

Dictionaries, casefold(), JSON, functions and menu-driven logic.

## How it works, step by step

1. Load contacts.json if it exists.
2. Add or update a contact using its name as a case-insensitive key.
3. View all contacts or search by name.
4. Delete a contact when requested.
5. Save changes after each operation.

## Files used

- main.py — contact operations. contacts.json

## How to run

1. Install Python 3.
2. Open this project folder in a terminal.
3. Run:

```bash
python main.py
```

On some systems, use `python3 main.py`.

## Learning note

Contact information is stored as plain JSON. Use fictional/sample details for classroom practice.

First run the project with sample data. Then trace how records change when you add, search, update or delete information.
