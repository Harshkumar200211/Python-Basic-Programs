# Project: Personal Expense Tracker

## What this project does

Record expenses with date, category, description and amount, then show category-wise totals.

## Python concepts used

Lists, dictionaries, date.today(), JSON, loops, sum() and aggregation.

## How it works, step by step

1. Enter a category, description and positive amount.
2. Attach today's date automatically.
3. Append and save the expense in expenses.json.
4. List all expenses.
5. Calculate total spending and category totals.

## Files used

- main.py — expense entries and reports. expenses.json

## How to run

1. Install Python 3.
2. Open this project folder in a terminal.
3. Run:

```bash
python main.py
```

On some systems, use `python3 main.py`.

## Learning note

Values are displayed in rupees. Monthly filtering can be added as an extension.

First run the project with sample data. Then trace how records change when you add, search, update or delete information.
