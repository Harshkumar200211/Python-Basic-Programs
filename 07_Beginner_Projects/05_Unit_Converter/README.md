# Project: Unit Converter

## What this project does

Convert distance, temperature and weight using a menu.

## Python concepts used

Functions, input, float, arithmetic, menu loops and formatted strings.

## How it works, step by step

1. Choose the required conversion.
2. Enter a numeric value.
3. Apply the conversion formula.
4. Display the value to two decimal places.
5. Return to the menu until Exit is selected.

## File used

- `main.py — menu and six conversion formulas.`

## How to run

1. Install Python 3.
2. Open this project folder in a terminal.
3. Run:

```bash
python main.py
```

On some systems, use `python3 main.py`.

## Learning note

Conversions: kilometres/miles, Celsius/Fahrenheit and kilograms/pounds. Console only; no frontend.

Try changing the inputs, tracing the variables and adding one small feature after the first successful run.
