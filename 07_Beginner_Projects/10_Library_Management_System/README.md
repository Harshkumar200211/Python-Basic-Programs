# Project: Library Management System

## What this project does

Maintain a small book catalogue and track book issues and returns.

## Python concepts used

Dictionaries, JSON, string input, conditions, menu loops and create/read/update/delete operations.

## How it works, step by step

1. Add a book with a unique book ID.
2. View the catalogue and availability status.
3. Issue an available book to a student.
4. Reject issue requests for missing or already-issued books.
5. Return a book and save every change in library.json.

## Files used

- main.py — book operations. library.json

## How to run

1. Install Python 3.
2. Open this project folder in a terminal.
3. Run:

```bash
python main.py
```

On some systems, use `python3 main.py`.

## Learning note

This console demo does not include member login, due dates or late-fine calculations.

First run the project with sample data. Then trace how records change when you add, search, update or delete information.
