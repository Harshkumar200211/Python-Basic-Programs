# Project: Multiple-Choice Quiz Application

## What this project does

Ask five Python MCQs, check answers and calculate a final score.

## Python concepts used

Lists, dictionaries, nested loops, string methods, conditions and score counters.

## How it works, step by step

1. Store each question, options and the correct answer in a dictionary.
2. Loop through the question list.
3. Validate that each answer is a, b, c or d.
4. Give feedback and increase the score when the answer is correct.
5. Display score and percentage at the end.

## File used

- `main.py — questions, options, answer validation and scoring.`

## How to run

1. Install Python 3.
2. Open this project folder in a terminal.
3. Run:

```bash
python main.py
```

On some systems, use `python3 main.py`.

## Learning note

Students can edit QUESTIONS to add more MCQs. Console only; no frontend.

Try changing the inputs, tracing the variables and adding one small feature after the first successful run.
