# Project: Number Guessing Game

## What this project does

Let a user guess a random number from 1 to 20 in a limited number of attempts.

## Python concepts used

random module, for loop, try-except, comparisons and break.

## How it works, step by step

1. Generate a random secret number.
2. Allow up to six attempts.
3. Validate each guess and provide a too-high or too-low hint.
4. Stop if the guess is correct.
5. Reveal the answer if attempts run out.

## File used

- `main.py — random selection, attempts and hints.`

## How to run

1. Install Python 3.
2. Open this project folder in a terminal.
3. Run:

```bash
python main.py
```

On some systems, use `python3 main.py`.

## Learning note

A non-numeric guess uses an attempt in this version. Console only; no frontend.

Try changing the inputs, tracing the variables and adding one small feature after the first successful run.
