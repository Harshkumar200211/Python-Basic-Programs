# Project: Calculator Using Custom Modules

## What this project does

Split arithmetic operations and geometry calculations into reusable Python modules.

## Python concepts used

User-defined modules, import statements, functions, math.pi and exception handling.

## How it works, step by step

1. Keep arithmetic functions in calculator_operations.py.
2. Keep rectangle and circle area functions in geometry.py.
3. Import both modules into main.py.
4. Choose an operation from the menu and enter the values.
5. Handle division by zero and negative geometry dimensions.

## Files used

- `main.py` — Menu and control flow.
- `calculator_operations.py` — Reusable add, subtract, multiply and divide functions.
- `geometry.py` — Rectangle and circle area functions.

## How to run

1. Install Python 3.
2. Open this project folder in a terminal.
3. Run:

```bash
python main.py
```

On some systems, use `python3 main.py`.

## Learning note

Run python main.py from this project folder. Keep all three files together so the imports work.

After the first run, change some inputs and explain how the code uses each listed concept.
