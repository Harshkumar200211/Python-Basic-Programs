# Contributing

Thanks for helping improve this beginner-friendly Python learning repository.

## Add or update a practice program

1. Keep each numbered example small, readable, and focused on one main concept.
2. Use a descriptive filename with its program number, such as `111_list_average.py`.
3. Include a short module docstring with the number and topic.
4. Prefer the Python standard library. Explain any new dependency before adding it.
5. Check normal input, invalid input where relevant, and boundary cases (for example zero, negative numbers, empty text, or missing data).
6. Update the numbered program index in `README.md`.
7. Add a sample-input and expected-output entry to `.github/scripts/test_practice_programs.py`. Update its count/range check if the program total changes.
8. Run the full checks listed in [TESTING.md](TESTING.md) before submitting changes.

## Add or update a beginner project

- Keep each project in its own directory under `07_Beginner_Projects/`.
- Include a project-level `README.md` with purpose, concepts, and run instructions.
- Add or update its sample-input smoke test in `.github/scripts/smoke_test_projects.py`.
- For file-writing examples, prefer predictable paths and do not include private or real personal data.

## Style and safety

- Use clear variable and function names and UTF-8 text.
- Avoid committing generated bytecode, virtual environments, secrets, personal contact details, or real student records.
- Be explicit when a program is a simplified learning example rather than a production-ready implementation.
